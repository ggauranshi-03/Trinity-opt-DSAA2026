# Extra & Archived Resources

This directory contains legacy artifacts, preliminary baseline experiment data, and batch cluster execution logs that are preserved for historical record and archival purposes, but are not required for the main DSAA 2026 benchmark suite.

---

## Directory Overview

```text
extra/
├── legacy_scripts/          # Early monolithic prototypes
├── baseline_experiments/    # Preliminary experiment runs (exp1, exp2, exp3)
└── slurm_master_logs/       # Cluster job scheduler output dumps
```

---

### 1. `legacy_scripts/`
Initial standalone monolithic scripts created during early development. Each script embedded data loading, model definition, optimizer, and training loop in a single file before the codebase was refactored into modular components (`datasets_lt.py`, `trinity_optimizer.py`, `train_*.py`):
- `custom100m_cifar10_10epochs.py`: 10-epoch pilot run of the 100M Transformer.
- `custom100m_cifar10_200epochs.py`: 200-epoch standalone script for the 100M Transformer.
- `resnet18_cifar10_300epochs.py`: 300-epoch standalone script for ResNet-18.
- `wide_resnet101_2_cifar10_200epochs.py`: 200-epoch standalone script for Wide-ResNet-101-2.

*Active modular replacements:* Use `train_resnet18_dsaa.py`, `train_wide_resnet_dsaa.py`, and `train_transformer_dsaa.py` in the workspace root.

---

### 2. `baseline_experiments/`
Data logs and CSV files from initial exploratory experiments comparing standard optimizers (SGD, Adam, RMSprop) against earlier hybrid formulations:
- `exp1.*`: Experiment 1 comparative logs and metric CSVs.
- `exp2.*`: Experiment 2 comparative logs and metric CSVs.
- `exp3.*`: Experiment 3 comparative logs and metric CSVs.

*Active benchmark results:* See `results_dsaa2026/` for the official DSAA 2026 paper benchmark evaluations.

---

### 3. `slurm_master_logs/`
Raw stdout and stderr dumps generated by the SLURM workload manager and `nohup` master runners on the compute cluster:
- `slurm_master_*.log`: SLURM batch job stdout from cluster nodes (e.g. `paramprabha` cluster).
- `master_*.log`: Terminal nohup output logs from batch ablation runner processes.

*Active training logs:* See `logs/` for detailed per-epoch training and validation logs.
